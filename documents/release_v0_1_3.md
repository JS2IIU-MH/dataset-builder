# Release v0.1.3 - 列順序変更機能の追加

**リリース日:** 2026-02-18

## 新機能

### 列の順序変更（ドラッグ&ドロップ）

データプレビュータブに、列の順序を直感的に変更できるドラッグ&ドロップ機能を追加しました。

**主な機能:**
- ドラッグ&ドロップで列の順序を自由に変更
- 変更前後のプレビュー表示
- 「適用」ボタンで変更を確定

**使用方法:**
1. データファイルをアップロード
2. 「データプレビュー」タブの「列の順序変更（ドラッグ&ドロップ）」セクションへ移動
3. 列名のボタンをドラッグ&ドロップして順序を変更
4. 「列の順序を適用」ボタンをクリックして変更を確定

**技術詳細:**
- `streamlit-sortables` ライブラリを導入
- `src/logic/data_io.py` に `reorder_columns()` 関数を追加
- `src/ui/forms.py` に `render_column_reorder()` UI コンポーネントを追加
